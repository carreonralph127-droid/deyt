# Date Invitation Website 💌

A fun and interactive website I built using HTML, CSS, and JavaScript.  
This project lets you send a creative "date invitation" online, with playful buttons and animations.

## Features
- 🎨 Clean and simple design
- 💕 Interactive "Yes/No" buttons
- ✨ Smooth animations and transitions
- 📱 Responsive layout (works on mobile and desktop)
